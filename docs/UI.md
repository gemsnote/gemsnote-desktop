# Desktop UI 约定

桌面端复用服务端 Vue 前端。三栏布局、笔记本树、搜索排序、默认预览、自动保存、
基本信息行、标签输入和树形移动选择器遵循 [Web UI 设计](https://github.com/gemsnote/gemsnote/blob/main/docs/development/UI.md)。
本文维护桌面端特有行为；本地缓存、登录和同步实现见[开发指南](DEVELOPMENT.md)。

## 导航与用户菜单

没有独立的最左全局导航栏。用户头像位于笔记本栏底部右侧，立即同步图标位于左侧。
笔记本栏收起为深绿色窄列后，顶部应用图标用于展开；底部竖排立即同步和用户头像。
从账号页面返回工作区时默认展开笔记本栏。

用户菜单包含同步子菜单（完全同步、重新同步）、账号、语言、关于、退出。
桌面端不显示管理入口，系统管理通过 Web 完成。关于对话框显示应用版本等信息。
账号页面顶部左侧显示应用品牌，右侧是返回按钮，不重复显示头像菜单。

## 保存与同步状态

本地 bridge / SQLite 提供离线数据，经服务端 API2 同步。本地自动保存成功不等于
已经上传服务端；不显示显式保存按钮或标题栏“已同步/未同步”文本。
待上传笔记在列表标题旁显示深绿色小点；立即同步图标使用浅绿色小点，以区别深绿色背景。
小点仅代表本地待上传数据，不以远端内容是否完整下载或后台媒体下载进度为依据。

立即同步成功后清除已上传数据对应的小点。完全同步、重新同步开始时先收起菜单，
打开进度对话框，完成后自动关闭，不在菜单中展示执行结果，也不额外弹出完全同步成功横幅。
同步失败须提供可见的错误提示。重新同步执行前确认将删除当前账号本地缓存并重新下载；
取消不得开始清理。媒体下载可在笔记同步完成、进度窗关闭后继续在后台进行。

## 退出与语言

退出前按同步规则处理本地变更；同步成功直接退出，失败才询问是否不同步退出。
确认则退出、取消则返回，保留后续登录同一账号时恢复本地未同步数据的能力。
对话框标题和按钮跟随所选语言，不使用浏览器默认英文确认框。
应用内文件选择控件使用当前语言；系统文件选择窗口自身由操作系统负责本地化。

## 验收要点

- 展开、折叠及窄屏时都能访问同步和用户菜单。
- 不显示 Web 管理入口，本地保存与服务端同步状态不混淆。
- 同步进度、失败提示、取消和退出确认行为正确。
- 中文和英文覆盖应用菜单与对话框；关于窗口正确显示版本。
